# PROJET EDABIT — GOMYCODE

**Thème :** Résolution de problèmes en JavaScript

## 1. Introduction

Dans le cadre de cette activité, j'ai réalisé un projet d'entraînement à la programmation avec Edabit. L'objectif est de résoudre des exercices de différents niveaux afin d'améliorer mes compétences en JavaScript.

## 2. Objectifs

- Développer la logique algorithmique.
- Comprendre les fonctions JavaScript.
- Utiliser les conditions et les opérateurs.
- Manipuler les tableaux et les chaînes de caractères.
- Tester et corriger les erreurs dans le code.
- Progresser dans les niveaux facile, moyen et difficile.

## 3. Technologies utilisées

- HTML : structure de la page.
- CSS : mise en forme et design.
- JavaScript : fonctions et tests.
- Edabit : plateforme de résolution de défis.
- Visual Studio Code : éditeur de code.

## 4. Exercices réalisés dans le projet local

### Niveau facile
1. Addition de deux nombres.
2. Conversion des minutes en secondes.
3. Retour du nombre suivant.

### Niveau moyen
4. Vérification d'un nombre pair.
5. Recherche du plus grand nombre.
6. Calcul de la somme d'un tableau.

### Niveau difficile
7. Vérification d'un palindrome.
8. Suppression des doublons d'un tableau.
9. Comptage des voyelles.

## 5. Résultats attendus

Le projet permet de consulter les solutions et de lancer les tests locaux. La progression affichée correspond aux exercices réussis dans cette démonstration.

Les défis Edabit doivent être résolus séparément sur la plateforme pour obtenir les points correspondants.

## 6. Conclusion

Cette activité m'aide à renforcer mes bases en programmation, à améliorer ma capacité à résoudre des problèmes et à mieux comprendre les algorithmes JavaScript.
